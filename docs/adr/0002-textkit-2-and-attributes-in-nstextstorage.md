# TextKit 2 and attributes in NSTextStorage

The editor is built on `NSTextView` with TextKit 2 (`init(usingTextLayoutManager: true)`). Styling is applied as attributes directly in `NSTextStorage`: `parse(text) -> [Span]`, then the theme maps kinds to a `TextStyle` (merging nested Spans) and the `TextStyle` to attributes, then they are applied to the storage. The `Styler` is the storage's delegate and restyles in `textStorage(_:didProcessEditing:range:changeInLength:)`, so attribute changes stay out of undo and every edit is covered, whoever makes it; attributes set there outside the edited range are picked up by TextKit 2 layout. The text stays plain, so ⌘C yields raw Markdown. Any access to `layoutManager` silently switches the view to TextKit 1, so it must not be touched: in DEBUG a fallback is caught by `assertionFailure`, and a test checks `textLayoutManager != nil`.
